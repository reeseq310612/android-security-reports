## 文档定位

- 面向安全研究、企业移动安全建设和应用开发安全实践。
- 以公开技术文档与安全公告为资料基准，强调证据链与可验证性。
- 区分“代码缺陷”“安全影响”和“实际可利用性”，不将通用风险描述等同于具体设备已存在漏洞。

## 使用说明

漏洞信息具有时效性。评估具体设备时，请以 Android 官方安全公告及设备厂商提供的补丁说明为准。
